# Spec 007: 阵容可视化展示

**Priority:** MEDIUM
**Dependencies:** Spec 003, Spec 008

## Description
使用 PySide6 自定义绘制推荐阵容的完整可视化：4×7 棋盘站位图、羁绊激活列表、装备合成路径。支持多阵容切换和拖拽调整棋子位置。

## Acceptance Criteria
- [ ] PySide6 自定义绘制 4×7 棋盘站位图
- [ ] 棋盘格子显示：棋子图标（或首字母替代）、名称、星级（★）、携带装备小图标
- [ ] 棋盘旁显示羁绊激活列表（已激活高亮、未激活灰色）
- [ ] 显示装备合成路径：当前已有散件 → 推荐合成装备的树状图
- [ ] 站位图支持鼠标拖拽调整棋子位置
- [ ] 多个推荐阵容时支持 Tab 或下拉切换查看
- [ ] 核心棋子与自由位棋子有视觉区分（如不同边框颜色）
