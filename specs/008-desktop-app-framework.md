# Spec 008: PyQt 桌面应用主框架

**Priority:** MEDIUM
**Dependencies:** None (can start independently, integrates with 007)

## Description
使用 PySide6 构建桌面应用主窗口，提供三栏布局（状态摘要、阵容可视化、行动建议），支持置顶、半透明、系统托盘最小化，不影响正常游戏体验。

## Acceptance Criteria
- [ ] PySide6 主窗口：置顶、半透明背景、无边框、不可聚焦（避免抢游戏焦点）
- [ ] 三栏布局：左侧状态摘要（等级/经济/血量/连胜连败/回合）、中间阵容可视化、右侧行动建议 + 关键决策高亮
- [ ] 底部状态栏显示：截图状态（等待中/处理中/完成）、LLM 调用次数、对局阶段
- [ ] 窗口支持最小化到系统托盘，托盘图标显示当前回合
- [ ] 支持深色/浅色主题切换，通过设置持久化
- [ ] 启动时检测英雄联盟客户端是否运行，未运行则显示友好提示
- [ ] 窗口大小可调节，面板比例可拖拽分割线调整
- [ ] 应用关闭时自动清理临时截图文件
- [ ] 只在 Windows 平台运行
